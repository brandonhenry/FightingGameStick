Three quick steps

From keyboard to controller.

  1. Install and launch Fighting Game Stick.
  2. Approve the signed ViGEmBus driver prompt on first run.
  3. Choose your bindings, press Enable, and launch your game.
The app installer is not yet Authenticode-signed, so Windows SmartScreen may ask you to choose “More info” and “Run anyway.”

Installed but can’t find it?

Create a desktop shortcut.

The installer places Fighting Game Stick in your Windows user folder. You do not need administrator access to open it.

Installed application %LOCALAPPDATA%\FightingGameStick\FightingGameStick.exe
  1. Press Win + R, paste %LOCALAPPDATA%\FightingGameStick, then press Enter.
  2. Right-click FightingGameStick.exe. On Windows 11, choose Show more options.
  3. Choose Send to → Desktop (create shortcut). You can also choose Pin to Start.

Use the EXE in the main FightingGameStick folder. Do not shortcut the copy inside an app-0.4.0 folder, because that versioned folder changes when the app updates. If you downloaded the Portable ZIP, the app remains wherever you extracted it.
